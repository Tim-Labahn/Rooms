# Legacy Features & Ideas Archive

This document preserves the features and ideas that were implemented or planned for the Rooms booking project before it was simplified.

## UI & Visualization
- **2D Interactive Map**: A coordinate-based layout where rooms and hallways were positioned on a grid.
- **Drag-and-drop Editor**: An admin interface allowing for real-time positioning and resizing of rooms, hallways, and sections.
- **Hallway Logic**: Specialized "hallway" elements that could be resized, automatically pushing adjacent rooms to maintain the layout.
- **Auto-Fit Zoom**: A system that automatically calculated the scale needed to fit all rooms/sections within the viewport on load and resize.
- **3D Building Model**: A WebGL/Three.js visualization of the building's rough shape, showing floors and sections in 3D.

## Planned/Removed Aesthetics
- **Main Office Symbol**: A decorative element for the building's main office.
- **Interactive Highlighting**: 3D model highlighting the currently viewed floor/section.
